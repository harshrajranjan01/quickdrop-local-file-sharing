BROWSER SUPPORT

HTTPS and direct transfers

Browsers restrict WebRTC on plain HTTP LAN addresses. Set up a trusted local certificate on the host and install its CA certificate on each phone to enable direct WebRTC transfers. Server uploads and relay transfers work over HTTP.

If devices can browse QuickDrop but cannot reach one another, the router may have client isolation enabled. Try the laptop hotspot or disable that router feature.

Optional private STUN/TURN server

For networks where direct connections are blocked, enter a STUN or TURN URL. Leave blank for same-network connections.
